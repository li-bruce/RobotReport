# 名册导入与时间设置

面向日常使用的完整步骤与截图：[会员版](MEMBER_GUIDE.zh-CN.md)、[管理员版](ADMIN_GUIDE.zh-CN.md)。以下保留操作规则与接口字段，页面位置以当前图文说明为准。


## 导入、补全与审核

进入 **人员中心 → 批量登记**，上传 Excel（`.xlsx`、`.xls`）或 CSV。系统识别常见中英文列名，在前20行查找表头，汇总可见的人员工作表，忽略无关列。核对“已识别的列”和人员预览后确认。每次最多2 MiB、1000人、100列、20张工作表；不执行宏；`.xlsx` 的资料列含公式时需先粘贴为数值。

每行姓名、手机号至少填一项。缺失项可以先留空；不会编造手机号或平台账号。无手机号行重复上传同一文件会跳过，换文件后，会按姓名、昵称、邮箱、学号、工号、会员号、微信号、证件号等已识别的身份列查找候选；性别、等级、组别不会单独判重。

对“待确认”行选择已有档案并点击 **确认匹配**，或选择 **不匹配，新增**。**批量确认匹配**只处理单一候选；多个同名候选需逐条选择。确认后保留原档案，不覆盖已有资料或绑定账号。全部核对完成后点击 **完成核对**；提交前会再次检查候选是否变化。

**新增预登记**只填个人资料，内部编号由系统分配。本人 @机器人发送 `注册` 或 `补全资料`，点击个人链接填写；账号来自机器人回调，无需填写ID。姓名、性别必填，自评1–9级、手机号选填。

**导入即核准会员资格。** 本人发送 `注册确认`，打开绑定本人群账号的链接。回调提供昵称时先查找同名资料；未提供昵称时本人填写姓名。唯一姓名匹配后，确认姓名和性别即可完成关联，不再审核会员资格；缺失手机号、自评级别可以补填，等级与组别留空不影响注册。本人新提交的自评级别仍单独待审。重名需提供登记手机号区分；已绑定其他账号的名册不能自动换绑。没有姓名匹配时，按正常注册申请审核。

**匹配已有会员**先预览唯一姓名匹配的现有会员，再批量关联；已有手机号不一致时不合并；补全资料时遇到同名同手机号会员会直接关联，不再报“已存在”后中断。重复预登记已有绑定档案时保留原会员及历史，将重复档案归入原档案。名称相同但手机号冲突、账号重复等情况保留待核对。已注册本人再次发送“注册确认”也会关联属于自己的唯一同名待确认档案。资料完整不等于已取得群账号；没有既有账号的人员首次关联仍需本人触发机器人。

勾选待关联人员，点 **通知本人确认**，选择负责注册的机器人，预览后发送。通知列出姓名并引导发送 `注册确认`；有导入邮箱时可用邮箱 @，仅有姓名时不能生成有效 @。当前平台回调不保证携带群昵称，因此支持 `注册确认 张三`。不会自动向所有群发通知。

**会员档案 → 申请待审**统一查看注册、等级和资料调整申请。通过“审核资料”核对修改前后内容；处理后在本人档案保留记录。管理角色仍需单独授权。

个人申请的审核回执沿用发起注册、资料或等级申请的机器人；来源机器人不可用时保持待发，不换成同群其他机器人。旧申请没有来源记录时，只从本人实际交互过的注册机器人中选择。个人结果需开启“会员注册”，无需开启“群内管理”。管理角色变更由管理机器人通知。办理审批仍需会员管理权限；群内审批还需机器人开启“群内管理”。

## 机器人管理与群关联

- **机器人管理**：展开机器人行，编辑名称、业务、场地、场次、用户条件和开放时间；查看动态帮助或删除机器人。
- **群关联**：旁侧新建、改名、删除群；点击连接图中的机器人或连线，选择群并配置发送 Webhook、复制回调地址。一个机器人仅有一个当前群，一个群可连接多个机器人。
- 连接可暂停或解除。发送地址可留空，接收指令可关闭。仅接收时，业务结果放在回调 HTTP 响应的 `reply` 字段，平台需支持处理该响应才会在群里展示；不会另发群消息。仅发送连接需选择已识别的群，发送测试通过后可用于公告和活动提醒。
- 接收连接使用私有回调地址认证；两端均配置的连接继续验证机器人密钥。回调地址应像密码一样保存。新群首次收到合法消息后自动识别，发送测试本身不提供可信群 ID。

## 定时播报

进入 **机器人与群 → 定时播报**，或展开某个机器人点击“定时播报”。可按机器人筛选，添加规则：

1. 勾选当日活动提醒、报名即将结束、报名名单，可多选。
2. 选择执行机器人，可多选；机器人需支持活动报名并开启活动提醒。
3. 设置北京时间、起止日期和指定星期。
4. 选择每天、工作日（含调休）、周六周日、休息日（含节假日），可再选跳过节假日或仅节假日。

规则可停用、删除；总开关暂停全部日常播报。同群、同一时刻、相同场次和类型只发送一次。只播报执行机器人负责的场次。大型赛事的阶段通知仍在赛事中配置。

未设置新规则时沿用原有三个提醒；保存空列表表示不播报。修改规则或关闭执行资格会取消旧的排队消息，过期到次日的消息不补发；服务重启不补发错过的提醒。工作日、休息日、节假日判断依赖年度日历，未知年份暂停匹配，请先在“节假日安排”获取当年数据。

## 机器人功能开放时间

进入 **机器人与群 → 机器人管理 → 编辑名称与功能 → 功能开放时间**，选择已开启的业务后设置规则：

- **仅这些时段开放**：只在任一开放规则满足时可用。
- **这些时段关闭**：关闭规则优先。
- 某项业务没有启用的时间规则时，按原业务开关全天提供。

时间起点包含、终点不包含；留空为全天。结束早于开始表示跨夜，日期和星期按起始日判断。例如周一22:00至02:00覆盖周二凌晨，02:00结束。日期范围包含首尾两天。全部使用北京时间。

固定指令、帮助、AI确认、本人表单及消息发送都遵守当前规则。规则只限制原有业务，不赋予会员或管理员权限。关闭某项基础业务时，会清理它的时间规则。

## 接口字段

| 接口 | 用途 |
| --- | --- |
| `POST /api/member-imports/preview` | 上传名册，返回列匹配、忽略的工作表、脱敏行、错误和预览令牌 |
| `POST /api/member-imports/matches` | 传入预览令牌及 `choices: [{source_key,target}]`，确认候选或 `new`；不修改会员 |
| `POST /api/member-imports/commit` | 一次性确认预览 |
| `PATCH /api/member-imports/records/{id}` | 补全资料；姓名手机号相同时关联已有会员 |
| `POST /api/member-imports/reconcile` | `record_ids` 可选；`commit=false` 预览，`true` 批量关联匹配人员 |
| `GET /api/member-imports/invite-channels` | 可收发注册消息的机器人 |
| `POST /api/member-imports/invite-preview` | `channel_id,record_ids` 预览确认通知 |
| `POST /api/member-imports/invite` | 加预览 `signature` 和随机 `request_id`，幂等加入发送队列 |
| `POST /public/registration/{reference}/lookup` | 本人链接内按姓名查找唯一未关联资料，不返回完整手机号 |
| `POST /api/members` | 不传 `user_id` 时生成预登记；保留可信管理员的旧账号接口 |
| `PATCH /api/config` | 保存 `broadcast_rules`；`null` 沿用旧提醒，`[]` 不播报 |
| `POST/PATCH /api/bots` | 保存 `capability_rules` |

播报规则字段：`id,name,enabled,kinds,bot_ids,time,when`。`kinds` 为 `open/closing/roster`。

功能规则字段：`id,name,enabled,capabilities,action,when`。`action` 为 `open/closed`。

共用日期条件：`start_date,end_date,weekdays,day_type,holidays`。星期一为0；`day_type` 为 `all/workday/weekend/restday`；`holidays` 为 `any/exclude/only`。功能规则另有 `start_time,end_time`。管理接口沿用权限校验；公开表单的账号、角色、审核状态不接受客户端指定。
