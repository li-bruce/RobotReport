# 管理页面操作说明

完整步骤和实际页面截图见 [管理员版操作说明](ADMIN_GUIDE.zh-CN.md)。可直接给会员分享 [普通用户版](MEMBER_GUIDE.zh-CN.md)。服务内地址分别为 `/guide/admin`、`/guide/member`。

| 页面 | 操作入口 |
| --- | --- |
| 人员中心 | 会员档案（含申请待审、通知记录）、批量登记、代报名访客、角色与权限 |
| 活动运营 | 报名日历、每日趣味赛、对局档案、报名统计、场地规划、活动时段、场地占用、节假日安排 |
| 大型赛事 | 对战与记分、参赛名单、分组结果、成绩排名、组织与协调、人员职务、照片与文件、流程记录 |
| 机器人与群 | 机器人管理配置业务和范围；群关联配置一机器人一群的收发连接 |
| 消息中心 | 编辑、预览、发布和发送记录 |
| 系统设置 | 账号与服务、定时播报、AI 设置、操作记录 |
| 使用指南 | 两版操作说明与对话演练 |

名册导入、本人账号关联和注册审批的步骤，统一以 [管理员注册流程](ADMIN_GUIDE.zh-CN.md#registration-admin) 为准；资料调整也在“会员档案 → 申请待审”办理。会员管理角色在“角色与权限”授予；网页登录使用后台管理员密码。

页面布局针对手机提供折叠导航与表格区域滚动。对话演练不会发群消息，但报名、取消、记分会修改业务数据；演练业务操作请使用独立测试环境。
