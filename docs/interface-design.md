# 聚场界面约定

聚场用于场地安排、活动报名和群机器人协作。管理者需要快速找到待处理事项，会员需要看懂下一步操作。

## 布局

- 管理导航按日常工作、群服务、设置分组；页面内保留相关功能切换。
- 工作台优先展示待审核和今日场次。统计用一排数据，近期动态只展示最近几条。
- 一页一个标题；主要操作靠近标题，补充说明通过“使用说明”进入对应章节。
- 机器人各项设置仍在本行展开，保存按钮与对应表单放在一起。
- 手机用抽屉导航；表格只在自身区域滚动，操作按钮保持可触达。

## 视觉

画布 #f5f5f7，内容 #ffffff，正文 #1d1d1f，次要文字 #64646b，边界 #d9d9df，品牌强调 #176b70。系统字体用于标题与正文；数字采用等宽数字。半透明材质仅用于导航与原有登录面板。

减少装饰性英文标题、重复说明、大面积彩色卡片和阴影。重要信息通过位置、字重和间距区分。场次清单保留时间轴式排列，形成与场地运营相关的识别点。

## 使用说明

普通用户版和管理员版分开。目录按任务编排；点击任务展开操作、回复和截图。搜索覆盖折叠内容，匹配后展开；外部章节链接自动展开目标。不依赖脚本也可阅读。

指令蓝色 #0066b2，填写内容棕色 #916100；同时使用“格式 / 示例”和括号说明，避免仅靠颜色传意。复制得到原始指令，不包含样式标记。

## 机器人帮助

“帮助”只展示当前机器人、当前用户可用的常用操作。详细格式通过“帮助 报名”等分类获取。示例和占位参数分色，管理操作继续按权限显示。注册状态、业务开放时间、负责场地和场次仍按原规则处理。

## 验证

检查桌面、平板与手机的导航、表单、滚动、弹窗、指令复制和深层链接。检查颜色对比、键盘焦点、减少动画设置，以及帮助的权限和业务范围。所有演示与截图使用虚构数据。

参考：[Apple 布局指南](https://developer.apple.com/design/human-interface-guidelines/layout)。采用内容分组、清晰层级和按需展开原则，保留 Web 平台的常用交互。
