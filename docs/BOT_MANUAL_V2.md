# 机器人使用说明

当前操作说明已按会员与管理员分开，并与实际页面及截图同步：

- [普通用户版](MEMBER_GUIDE.zh-CN.md)：注册确认、资料申请、报名和代报、每日趣味赛、大型赛事参赛、对局记录、AI 办理和反馈处理。
- [管理员版](ADMIN_GUIDE.zh-CN.md)：名册导入、账号关联、审批和续费、角色权限、机器人与群、活动安排、消息和办赛流程。
- [赛制与人数条件](formats.md)。

服务内访问 `/guide/member` 或 `/guide/admin`。在群里 @当前机器人发送 `帮助`，查看它已开启的功能；`帮助 注册` 查看注册简明用法。本人链接自动带入群账号，无需填写 ID。

管理员已导入的唯一姓名匹配后，由本人确认直接注册；重名填登记手机号区分，未匹配才进入审核。会员资格、等级、会籍和管理角色分别办理，详情见上方对应操作说明。
