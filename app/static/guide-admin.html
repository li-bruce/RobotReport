02

机器人接入与分工

1. 新建群，再添加机器人

  1. 进入机器人与群，点击新建群，只填群名称。
  2. 在该群下点击添加机器人；也可点击页面顶部新建机器人。
  3. 填写机器人名称、勾选业务。默认开启注册、报名、每日赛事、零散对局、统计和消息发布；AI、大型赛事、群内管理默认关闭。所有业务都可单独取消。
  4. 需要限制场地或场次时，展开场地与场次范围选择；默认负责全部。

机器人名称旁直接显示负责的场次、时间和业务。点击机器人行可展开设置，再次点击收起。

打开机器人与群 →

2. 同一页面配置收发地址

  1. 进入连接群，选择已经建好的群。
  2. 把金山协作群内这个机器人的发送 Webhook粘贴到后台。需要单独验证发送时，可点保存并测试发送，群里会收到测试消息。
  3. 在同一个窗口复制机器人回调地址，填到金山协作同一个机器人的“消息接收地址 / 回调地址”。两边保存即可，填写和复制不分先后。
  4. 回到群内 @这个机器人，发送 连接。后台识别群 ID，显示已连接。随后发“帮助”查看可用功能。

无需填写群 ID 或 Robot Key。同群的每个机器人分别使用自己的两个地址，并单独完成测试。

3. 修改分工、换群或暂停

  1. 展开机器人，点击编辑设置修改名称、业务、场地和场次；用帮助预览检查群成员看到的指令。帮助会随业务开关、负责场地与场次即时变化，每项列出字段和可发送的示例；可切换会员、未注册用户和管理员预览。
  2. 点击编辑连接修改发送地址。换群时选择已有群，重新粘贴目标机器人的发送 Webhook，再去目标群 @它发送“帮助”。
  3. 直接点击接收指令或活动提醒开关调整接收与提醒。
  4. 暂停连接可临时停止使用；解除连接后可重新选群连接。历史记录保留。

新群先在页面外层新建。群名称可用群标题旁的“重命名”修改。场地和时段只需在机器人设置中配置。

按用户属性限制使用

  1. 展开机器人 → 编辑设置 → 用户使用条件，勾选启用。
  2. 点击添加条件，选择属性、匹配方式和取值。可配置组别、已审核等级、性别、注册状态、角色、权限、姓名、账号、手机号、自评和审核信息、会籍状态及日期等。
  3. 选择全部满足或任一满足，保存设置。

例如学生女双：组别包含“学生”、性别属于“女”、已审核等级不低于3，选择“全部满足”。范围3–6级，再加一条等级不高于6。

条件限制发指令的账号，也适用于群内管理员。注册、本人资料、补充性别、自评和帮助保留入口；业务仍需原有会员资格和管理权限。群里仅提示未满足的属性，不展示手机号或审核备注。新报名仍受会籍和活动要求限制；会籍到期查看历史的原有规则不变，除非另外启用本机器人的会籍条件。

删除不再使用的机器人

展开机器人，点击删除机器人并确认名称。它会停止收发、解除连接，从当前机器人列表移除。会员、报名、赛事、历史消息和同群其他机器人保留；已发出的消息不会撤回。

后台删除不会移除金山协作群中的机器人；需要时在金山协作中移除。只想暂时停用，可关闭“启用机器人”；只换群，用“编辑连接”。

04

日常活动与报名

场地、场次与报名日历

  1. 在活动运营 → 场地规划维护场地名称、位置与启停状态。
  2. 在活动时段在周期性时段新增或编辑规则，填写星期、名称、起止时间、正式及替补人数，选择是否跳过节假日，再勾选应用场地。相同规则可同时用于多块场地。
  3. 临时加场或改时间，切换到非周期性时段 → 新增日期安排，选择日期和场地后保存；也可恢复该日原有周期或节假日安排。
  4. 打开报名日历先看日期格内的报名人数、正式/替补进度条、场次及场地数量。周末、节假日、调休上班日、比赛日有独立标记；选中日期后按场地查看各场次，展开单场名单；可筛选场地、状态、名称或时间，每页最多12场。未结束场次可添加、取消报名或调整人数和报名条件；历史报名只读。

改时段会调整尚未开始的未来安排和预约；历史及已开始场次保留原时间。赛事锁定的场次需先处理赛事。

打开报名日历 →

登记其他活动占用

  1. 进入活动运营 → 场地占用，在页面内选择场地。
  2. 点击登记占用，填写用途、日期、开始和结束时间并保存。训练、维修、借用等均可登记。
  3. 日历和相关机器人显示不可报名；与该时段重叠的整个日常场次暂停新报名，已有报名保留。可在日历查看受影响名单并协调。
  4. 需要撤销时点击释放；未开始的其他活动占用可以编辑。大型赛事占用请到赛事页面调整。

同一场地的两项占用不能重叠。占用登记或释放后，开启活动提醒的相关群会收到通知；同一实际群只发一次。

具备活动管理权限且机器人开启群内管理时，可发送 场地1 明天 占用 17:30-20:30 校队训练、场地1 释放占用12。编号从占用查询中获取。

AI示例：AI 明天场地1从17点半到20点半安排校队训练占用，再查看占用情况；核对步骤后回复“确认”。

管理场地占用 →

逐个安排节假日

  1. 进入活动运营 → 节假日安排，选择场地和年份。点击获取 / 更新节假日加载当年的假期列表。
  2. 展开一个假期，核对开始、结束日期，设置各场的名称、起止时间、正式和替补名额。
  3. 勾选使用本假期专用场次并保存。启用但移除全部时段表示假期暂停日常报名；关闭时按周期规则执行，其中勾选“跳过节假日”的规则不执行。
  4. “非周期性时段”指定日期的安排优先。机器人若只负责部分场次，在机器人与群中选择相应假期场次。

刷新年度数据保留手工安排；已结束的假期只读。已有预约或赛事锁定导致无法切换时，按提示保留原场次后调整。

群中管理命令：节假日设置查看当年假期；开启节假日 / 关闭节假日批量开关本场地的假期专用安排。

举办大型赛事

办赛前：确定项目、人数和人员

先确定比赛日期、场地、预计人数、单打或双打；双打再选普通双打、男双、女双或混双。确定负责人、记分员和协调员。

积分赛适合循环交手；单淘汰和双败淘汰适合晋级比赛；分组淘汰先小组循环再淘汰。五人转、五羽伦比、双打轮转适合相应人数和组队形式。

创建时会提示赛制适用条件；具体轮转和人数说明见每日赛事赛制说明。

1. 创建赛事草稿

  1. 进入大型赛事 → 组织大型赛事，确认顶部所选场地。
  2. 填写赛事名称、日期、比赛项目、赛制和群报名关键词，例如赛事名“春季联赛”、关键词“春季联赛”。
  3. 设置报名开始/结束时间、组别与等级要求；分组淘汰同时检查分组数、每组晋级人数。
  4. 选择组队算法、计分参数后保存。先核对草稿，再开放报名。

大型赛事有独立报名期，关联日常活动场次为可选项。文字“规则说明”用于补充规程，计分参数需在赛事设置中填写。

打开大型赛事 →

2. 指定负责人和负责机器人

  1. 打开赛事的组织安排，填写赛事介绍、规则说明、集合与到场安排。
  2. 在负责机器人与通知群勾选接收群并保存。可选多个机器人；同一次通知每个实际群只发一份。
  3. 在赛事职务选择已审核会员，分别指定负责人、记分员、协调员和授权起止时间，保存。

候选机器人应已启用大型赛事、负责赛事场地并连接可发送的群。日常场次限制不影响大型赛事。未选通知群时，后台建赛不会自动发群消息。

3. 开放报名并发群公告

  1. 点击开放报名，状态进入“报名中”；用户报名仍须在所设时间窗口内。
  2. 用发布赛事消息选择报名通知，核对接收群后发送。
  3. 在参赛名单中查看新增人员；在发送记录中核对公告结果。

4. 结束报名，核对名单

  1. 截止后查看状态；需要提前截止时点击结束报名。
  2. 核对参赛人数、性别、组别、等级和队伍配置，处理名单疑问。
  3. 发布报名结束通知，告知成员等待分组与赛程。

报名截止后不能再按报名指令新增或取消人员。请在抽签前确认名单和规则；人数不足时先解决参赛规模，再继续编排。

5. 抽签分组并排赛

  1. 确认“报名结束”后点击生成分组与编排，生成队伍、分组和对战表。
  2. 在对战/赛程安排中填写每场的比赛时间和球场，保存。
  3. 检查球场、开赛时间和上场顺序，给转场与休息留出时间。
  4. 发布分组结果和赛程，提醒球友查询自己的安排。

组队可选随机、种子分布、平均分布或高带低；五人转按固定轮转规则。生成对战后不要重新组织一场同名比赛；保留本次对阵继续办理。

7. 暂停、继续与晋级

小组赛完成后按规则晋级。出线边界完全同分时，由负责人点击同分抽签并晋级，完成有记录的抽签。

若后续晋级比赛已经开始，上游改分可能受限；先核对赛程关系。终止整项赛事才用关闭，关闭不能恢复，也不会为未完赛事判冠军。

8. 发布赛果与归档

  1. 全部比赛结束后，核对积分、胜负及最终获胜者。
  2. 发布成绩通知，提醒参赛者查询 春季联赛，积分表。
  3. 在赛事工作室上传比赛照片和文件，整理赛程及协调记录。
  4. 完成核对后归档，以后从历史赛事查看；归档后不再继续报名或记分。

长周期赛事途中只需暂停和恢复；归档留到所有赛果、照片及资料整理完成后。

每日趣味赛怎么管理

日常约球由已报名会员在群内发送“组织比赛”，再选择可用赛制；发起人就是组织者。无需为每次日常约球新建大型赛事。

管理员在活动运营 → 每日趣味赛查对战、修正比分、暂停或恢复赛事；需更换记分人员时调整本赛事职务。

先预留比赛场地与时间

创建大型赛事时，先选择比赛场地、活动日期、占用开始与结束，再填写赛事名称、赛制和报名窗口。报名窗口不是场地占用时间。

赛事草稿创建后即预留场地；日常场次显示占用并暂停新报名。若与其他已登记活动冲突，调整时间或先释放原占用。

多日赛事或后续调整：打开组织安排 → 配置赛事占用，逐段添加日期和起止时间。安排具体对局时，开始时间应在赛事预留范围内。已开始的占用保留历史；关闭或归档赛事释放预留，暂停比赛仍保留场地。

旧赛事若提示“尚未预留场地”，请补充占用时间后再开展活动。

消息、AI与系统

提醒与群消息

定时提醒：在“系统设置 → 定时提醒”设置报名提醒、截止提醒、名单播报的时间和开关。

临时通知：进入“消息中心”，选接收群，编辑文字、添加图片或文件，获取预览后确认发布。

发完到“发送记录”检查结果；已加入队列时先等待，结果待确认时先核实群里是否收到。

图片、文件上传完成后再发送。一次选中同群的多个机器人，也只发送一份。

常见问题处理

接入与通知问题

@机器人后没有回复
先确认@目标机器人。检查机器人和群连接是否启用、是否接收指令；在金山端核对本机器人的回调地址，再检查发送Webhook。保存后以“帮助”验证。
群里有两个机器人，只有一个响应
两个机器人分别使用自己的发送Webhook和回调地址；在连接编辑中选择同一个群。审核、角色、等级和组别通知仅由开启“群内管理”的机器人发送；报名、赛事和普通公告按业务范围共享，同群只发送一次。
一直显示“等待群内验证”
核对后台发送地址和金山端回调地址属于同一个机器人，保存后回到所选群 @它发送“连接”。可在后台点击“查看连接状态”，分别检查发送和接收是否已验证。
机器人提示“未开启”或场次不在负责范围
编辑机器人的业务和场地/日常场次；群连接无需再配置活动范围。发送“帮助”核对最新业务。
AI全局已开启，机器人仍不能用
还需在这个机器人的业务中勾选“AI助手”，然后@它发送“AI状态”。

办赛时遇到这些提示

选不到负责机器人
检查机器人已开启大型赛事、负责赛事场地、已连接启用的群并配置发送Webhook，再回赛事的组织安排选择。
尚未开放报名 / 报名已结束
检查赛事状态和起止时间；仅填写时间没有开放报名时，先执行“开放报名”。已抽签后不能更改报名窗口。
不能抽签 / 人数或性别不满足
先结束报名，再核对所选赛制的最低人数、组队要求和性别资料。已生成对战时继续原赛事，不重新抽签。
无本赛事记分权限 / 尚未开放记分
检查用户已审核、赛事职务及授权期，再检查赛事是否已开赛、该对局是否就绪。普通参赛者不会自动获得记分权。
排赛冲突 / 尚不能晋级
检查相同球场与开赛时间；分组淘汰需先完成小组赛，出线同分按页面提示办理。不同时间但时长重叠的比赛也要人工核对。
页面数据已变化
刷新赛事页面，重新核对名单、状态与安排后再提交，避免把别人刚改的内容覆盖。

管理员发送与通知记录

“待发送 / 发送中”
消息正在排队或发送，稍后刷新发送记录，不要反复点发布。
“已发送”
平台已接受消息；可到群里核对，状态不代表成员已读。
“失败”
查看发送记录中的原因，修正机器人发送地址、附件或配置后，再按页面可用操作处理。
“结果待确认 / 部分发送”
先核对群里已收到哪些内容；未确认前不要整条重复发送，必要时只补发缺失部分。
身份通知待处理、受阻或群绑定不可用
审核结果可能已经生效。先核对会员状态，再确认关联群至少有一个机器人开启“群内管理”并配置发送Webhook；仅对页面允许重试的通知重试。
