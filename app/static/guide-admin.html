02

机器人接入与分工

1. 机器人管理：名称与分工

  1. 进入机器人与群 → 机器人管理，点击新建机器人。
  2. 填写名称，勾选业务。注册、报名、每日赛事、零散对局、统计和消息默认开启；AI、大型赛事、群内管理默认关闭。
  3. 按需设置场地、场次、用户条件及功能开放时间，保存。
  4. 点击机器人行展开，直接编辑名称与功能、服务范围、用户条件、功能开放时间，点击保存机器人设置。下方定时播报单独保存。

收起时显示关联群、场地、业务、服务场次与播报时间。展开后的设置都属于当前机器人；收起再展开会保留未保存的输入。连接地址仍在“群关联”分页配置。

打开机器人管理 →
看图操作：机器人管理

2. 群关联：点击连线配置

  1. 切到群关联，新建群只填名称。
  2. 点击图中的机器人或连线，选择群，粘贴群里提供的发送 Webhook。
  3. 复制机器人回调地址，填到平台上同一个机器人的消息接收设置。两个地址可一起配置。
  4. 点击保存并测试发送，然后在群里 @对应机器人发送连接；后台显示“已连接”。

一个群可连多个机器人，一个机器人只连一个群。群 ID 自动识别，无需输入。左侧可改名、删除群；连接弹窗可暂停或解除。

仅接收时可留空发送地址；仅发送时关闭“接收群指令”，并选择已识别的群。接收结果能否直接显示在群里，取决于平台是否支持回调响应。

3. 修改分工、换群或暂停

  1. 展开机器人，点击编辑名称与功能修改名称、业务、场地和场次；用帮助预览检查群成员看到的指令。帮助会随业务开关、负责场地与场次即时变化，每项列出字段和可发送的示例；可切换会员、未注册用户和管理员预览。
  2. 切到群关联，点击连线修改发送地址。换群时选择已有群，重新粘贴目标机器人的发送 Webhook，再去目标群 @它发送“帮助”。
  3. 直接点击接收指令或活动提醒开关调整接收与提醒。
  4. 暂停连接可临时停止使用；解除连接后可重新选群连接。历史记录保留。

在群关联页新建群；群列表中的“编辑”可修改名称。场地和时段只需在机器人设置中配置。

限制功能开放时间

编辑名称与功能 → 功能开放时间，选择本机器人已开启的功能，添加“仅这些时段开放”或“这些时段关闭”。可设置日期、星期、节假日和时段；关闭优先。时间留空为全天，22:00–02:00表示跨夜，按开始日判断星期。保存后帮助、指令、AI确认、个人表单和发送都按当前时间执行。

按用户属性限制使用

  1. 展开机器人 → 编辑名称与功能 → 用户使用条件，勾选启用。
  2. 点击添加条件，选择属性、匹配方式和取值。可配置组别、已审核等级、性别、注册状态、角色、权限、姓名、账号、手机号、自评和审核信息、会籍状态及日期等。
  3. 选择全部满足或任一满足，保存设置。

例如学生女双：组别包含“学生”、性别属于“女”、已审核等级不低于3，选择“全部满足”。范围3–6级，再加一条等级不高于6。

条件限制发指令的账号，也适用于群内管理员。注册、本人资料、补充性别、自评和帮助保留入口；业务仍需原有会员资格和管理权限。群里仅提示未满足的属性，不展示手机号或审核备注。新报名仍受会籍和活动要求限制；会籍到期查看历史的原有规则不变，除非另外启用本机器人的会籍条件。

删除不再使用的机器人

展开机器人，点击删除机器人并确认名称。它会停止收发、解除连接，从当前机器人列表移除。会员、报名、赛事、历史消息和同群其他机器人保留；已发出的消息不会撤回。

后台删除不会移除机器人平台群中的机器人；需要时在机器人平台中移除。只想暂时停用，可关闭“启用机器人”；只换群，到“群关联”点击当前连线。

03

会员、审核与角色

先选注册方式，再处理申请

管理员已有名单：批量登记 → 核对重复人员 → 完成核对 → 通知本人确认 → 本人姓名匹配并提交 → 直接成为会员。

没有预登记名单：本人 @机器人“注册” → 填表提交 → 会员档案“申请待审” → 审核通过或退回 → 原注册机器人通知本人。

导入即核准会员资格，但不会凭姓名生成群账号。只有本人触发机器人，或与已有会员匹配关联后，档案才显示“已关联”。等级审核、会籍续费、管理角色是后续独立操作。

① 导入与核对② 关联与通知③ 审核申请④ 续费记录

1. 导入名册，先核对人员

人员中心 → 批量登记

  1. 选择 Excel（.xlsx / .xls）或 CSV，点击上传并预览。可用原有表格，不必先改成模板。
  2. 展开已识别的列，核对姓名、手机号、性别、等级和组别是否对应正确。未知列会忽略；姓名与手机号至少填一项。
  3. 处理待确认行：选择确为同一人的档案，点击确认匹配；不同人点击不匹配，新增。批量确认匹配只处理单一候选，重名多候选逐条选择。
  4. 有错误先修改文件重新上传；全部核对后点击完成核对 · 新增 N 人。预览阶段尚未导入。
  5. 在预登记档案查看结果。缺失资料可点补全资料；姓名、手机号都匹配已有会员时会关联，冲突时先核对档案。

无手机号时，可按姓名、昵称、邮箱、学号、工号、会员号等身份列查找候选；性别、等级和组别不单独判定为同一人。确认重复人员保留原档案，不用导入覆盖原会员。

每次最多 1000 人、2 MiB。手机号、等级、组别可留空；多个组别在文件中用分号分隔。点击“下载 CSV 模板”可查看标准列名。

看图操作：上传入口与重复人员核对

2. 关联群账号，通知本人确认

人员中心 → 批量登记 → 预登记档案

  1. 已有注册账号：点击“匹配已有会员”，先看匹配原因，再点击“关联匹配的 N 人”。唯一姓名匹配且已有手机号不冲突时可关联；有冲突的先核对。
  2. 还没有群账号：勾选待关联人员，点击“通知本人确认”，选择负责注册的机器人 / 群。
  3. 点击预览通知，核对姓名和发送群，再点发送确认通知。进入发送记录查看结果。
  4. 成员收到通知后 @该机器人发送注册确认，打开本人链接核对姓名和性别。唯一姓名匹配即完成；重名时补登记手机号。
  5. 点击刷新档案，或将“关联状态”切换为“已关联”核对。

姓名、手机齐全不等于已关联账号；级别、组别为空也不影响注册。只有姓名时通知会列出姓名，不会凭名字自动生成有效 @；有可用邮箱时可按邮箱 @。

通知只发到预览选中的机器人 / 群，不会随导入自动群发。可选机器人需开启“会员注册”、接收群指令，并配置发送地址。

看图操作：通知本人确认

3. 审核注册、等级和资料申请

人员中心 → 会员档案 → 申请待审

  1. 点击申请待审，找到需要处理的会员。
  2. 注册申请点审核申请，核对真实姓名、性别等资料，将会员状态设为“正式会员”或“申请未通过”，填写备注并保存会员资料。
  3. 等级申请点审核等级单独处理；资料调整点审核资料，比较原资料与新内容，选择通过或退回并保存。
  4. 回到档案检查结果；点击通知记录核对是否已发送。本人档案保留申请与审核记录。

办理审核需要会员管理权限。导入名册匹配完成的会员不再审批注册；若只剩等级或资料申请，只处理对应申请。

4. 维护资料、等级和组别

人员中心 → 会员档案

用管理组别维护可用组别；打开本人档案可编辑姓名、性别、手机号和组别。等级支持 1–9 级，自评申请通过后才显示已核准等级。不要用重复导入修改已关联会员。

会员也可发送“修改资料”“申请分组 提高组”“申请等级 5级”。这些申请统一进入申请待审，审核前原资料生效。分组申请提交的是完整组别列表。

注册、个人资料、等级与组别通知由“会员注册”机器人发布；本人申请优先沿用发起申请的机器人。它暂时不可用时保留待发，不换成同群的另一个机器人。管理角色变更由“群内管理”机器人通知。

5. 登记会籍与每次续费

人员中心 → 会员档案 → 本人行“续费记录”

  1. 先确认会员资格已通过，再打开续费记录。
  2. 展开登记一段有效期，填写开始日期、结束日期；可点击按开始日填写一年，金额和备注选填。
  3. 点击保存有效期。下一次续费新增一段，不覆盖原记录；两次可有间隔。
  4. 登记有误时作废对应记录并说明原因，再录入正确时间。

起止日期均包含在有效期内。到期或处在续费间隔期，不能新增报名，仍可查历史、取消已有报名；预约还需覆盖活动当天。会员发“我的会籍”可查。

“有效期待设置”表示尚未录入：当前已审核会员仍可报名，请补录实际会籍。续费不代替注册审核，也不会授予管理角色。

注册与通知问题：按现象处理

现象管理员检查与操作
导入后仍显示“待本人确认”这是已核准名册，尚未关联群账号。已有会员用“匹配已有会员”；其他人用“通知本人确认”。
补手机号时提示已有人员或绑定冲突同名同手机号的已注册会员可关联。姓名不同、手机号冲突或已绑他人时先核对档案，不反复新增。
成员称已导入，仍出现待审核核对姓名是否与名册一致；回调未带姓名时用“注册确认 张三”。重名补手机号，必要时在档案中核对。
名册只有手机号，成员不知道如何确认可先“补全资料”补姓名；也可让本人在注册链接填写姓名、性别和登记手机号，手机号唯一匹配后关联。
注册链接缺失或无法打开检查“系统设置 → 账号与服务 → 公共服务地址”是否正确且可访问。保存后让成员重新发送“注册”，使用新链接。
找不到资料调整申请在“会员档案”点“申请待审”，找到该会员的“审核资料”；无需另找独立页面。
选不到通知机器人检查该机器人已启用、开启会员注册、接收群指令，并连接可发送的群。
提示“请重新预览通知后发送”重新打开通知窗口，核对人员与机器人，点击“预览通知”再发送；修改发送群或名单后须重新预览。
审核成功但群里没收到通知先查会员资格和“通知记录”。检查原申请机器人及连接是否可用、是否开启会员注册，再处理页面允许重试的通知。不要重复审批。
“待发送 / 已发送 / 结果待确认”待发送先等队列；已发送表示接口已接受；结果待确认先核对群里是否收到，避免重复发布。
成员已通过仍不能报名查会籍是否覆盖活动日期，再查机器人业务、用户条件、场地场次、开放时间及活动组别/等级要求。
04

日常活动与报名

场地、场次与报名日历

  1. 在活动运营 → 场地规划维护场地名称、位置与启停状态。点击编辑场地 → 添加属性，填写属性名称和内容，例如“运动类型：羽毛球”“室内外：室内”“配套设施：储物柜”。保存后显示在场地卡片中；可增删，最多20项。
  2. 在活动时段在周期性时段新增或编辑规则，填写星期、名称、起止时间、正式及替补人数，选择是否跳过节假日，再勾选应用场地。相同规则可同时用于多块场地。
  3. 临时加场或改时间，切换到非周期性时段 → 新增日期安排，选择日期和场地后保存；也可恢复该日原有周期或节假日安排。
  4. 打开报名日历先看日期格内的报名人数、正式/替补进度条、场次及场地数量。周末、节假日、调休上班日、比赛日有独立标记；选中日期后按场地查看各场次，展开单场名单；可筛选场地、状态、名称或时间，每页最多12场。未结束场次可添加、取消报名或调整人数和报名条件；历史报名只读。

改时段会调整尚未开始的未来安排和预约；历史及已开始场次保留原时间。赛事锁定的场次需先处理赛事。

登记其他活动占用

  1. 进入活动运营 → 场地占用，在页面内选择场地。
  2. 点击登记占用，填写用途、日期、开始和结束时间并保存。训练、维修、借用等均可登记。
  3. 日历和相关机器人显示不可报名；与该时段重叠的整个日常场次暂停新报名，已有报名保留。可在日历查看受影响名单并协调。
  4. 需要撤销时点击释放；未开始的其他活动占用可以编辑。大型赛事占用请到赛事页面调整。

办赛前：确定项目、人数和人员

先确定比赛日期、场地、预计人数、单打或双打；双打再选普通双打、男双、女双或混双。确定负责人、记分员和协调员。

积分赛适合循环交手；单淘汰和双败淘汰适合晋级比赛；分组淘汰先小组循环再淘汰。五人转、五羽伦比、双打轮转适合相应人数和组队形式。

创建时会提示赛制适用条件；具体轮转和人数说明见每日赛事赛制说明。

1. 创建赛事草稿

  1. 进入大型赛事 → 组织大型赛事，在创建表单中选择比赛场地和占用起止时间。

  3. 设置报名开始/结束时间、组别与等级要求；分组淘汰同时检查分组数、每组晋级人数。
  4. 选择组队算法、计分参数后保存。先核对草稿，再开放报名。

大型赛事有独立报名期，关联日常活动场次为可选项。文字“规则说明”用于补充规程，计分参数需在赛事设置中填写。

常见问题处理

接入与通知问题

@机器人后没有回复
先确认@目标机器人。检查机器人和群连接是否启用、是否接收指令；在机器人平台核对本机器人的回调地址，再检查发送Webhook。保存后以“帮助”验证。
群里有两个机器人，只有一个响应
两个机器人分别使用自己的发送Webhook和回调地址；在连接编辑中选择同一个群。个人申请的审核结果由发起申请的机器人发送，需开启“会员注册”；该机器人停用时保持待发，管理角色变更由“群内管理”机器人发送；报名、赛事和普通公告按业务范围共享，同群只发送一次。
一直显示“等待群内验证”
核对后台发送地址和机器人平台回调地址属于同一个机器人，保存后回到所选群 @它发送“连接”。可在后台点击“查看连接状态”，分别检查发送和接收是否已验证。
机器人提示“未开启”或场次不在负责范围
编辑机器人的业务和场地/日常场次；群连接无需再配置活动范围。发送“帮助”核对最新业务。
AI全局已开启，机器人仍不能用
还需在这个机器人的业务中勾选“AI助手”，然后@它发送“AI状态”。

办赛时遇到这些提示

选不到负责机器人
检查机器人已开启大型赛事、负责赛事场地、已连接启用的群并配置发送Webhook，再回赛事的组织与协调选择。
尚未开放报名 / 报名已结束
检查赛事状态和起止时间；仅填写时间没有开放报名时，先执行“开放报名”。已抽签后不能更改报名窗口。
不能抽签 / 人数或性别不满足
先结束报名，再核对所选赛制的最低人数、组队要求和性别资料。已生成对战时继续原赛事，不重新抽签。
无本赛事记分权限 / 尚未开放记分
检查用户已审核、人员职务及授权期，再检查赛事是否已开赛、该对局是否就绪。普通参赛者不会自动获得记分权。
排赛冲突 / 尚不能晋级
检查相同球场与开赛时间；分组淘汰需先完成小组赛，出线同分按页面提示办理。不同时间但时长重叠的比赛也要人工核对。
页面数据已变化
刷新赛事页面，重新核对名单、状态与安排后再提交，避免把别人刚改的内容覆盖。

管理员发送与通知记录

“待发送 / 发送中”
消息正在排队或发送，稍后刷新发送记录，不要反复点发布。
“已发送”
平台已接受消息；可到群里核对，状态不代表成员已读。
“失败”
查看发送记录中的原因，修正机器人发送地址、附件或配置后，再按页面可用操作处理。
“结果待确认 / 部分发送”
先核对群里已收到哪些内容；未确认前不要整条重复发送，必要时只补发缺失部分。
身份通知待处理、受阻或群绑定不可用
审核结果可能已经生效。先核对会员状态。个人审核结果请检查原申请机器人的发送连接及“会员注册”；管理角色变更请检查“群内管理”机器人；仅对页面允许重试的通知重试。
