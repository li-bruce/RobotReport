注册与开始使用

先看机器人能做什么

在群里 @要使用的机器人，发送 帮助。不同机器人可能负责不同业务、场地或场次。

第一次使用先注册；审核通过后，按日期和场次报名。同一后台内换群不用重新注册。

每日趣味赛

会员可发起

每日趣味赛

  1. 先报名，再发送 组织比赛。机器人会列出人数及可用赛制。
  2. 需要指定项目，可发送 组织比赛 混双；也支持单打、双打、男双、女双。
  3. 回复可用赛制，例如 积分赛，生成对战表。
  4. 发起人是组织者，负责记分、改分与暂停；完赛后查看积分表和赛果。

默认普通双打。正式人数不足时，可按顺序补入符合条件的替补。混双每队一男一女，男双、女双须符合性别要求。

选一种合适的赛制

发送“组织比赛”后的可用列表，会按当前人数、项目和性别组合筛选。

积分赛

单打或固定双打，每对对手交手一次；按胜场、局净胜、分净胜排名。

五人转

恰好5人、5场双打。每人打4场、轮空1场，每对搭档合作1次，按个人排名。

双打轮转

4–40人轮换搭档，优先安排出场较少者；按个人成绩排名。

五羽伦比

至少10人、人数为5的倍数。每队5人轮换搭档，默认团队50分追逐赛；登记团队总比分。

单淘汰

输一场出局，胜者晋级；适合较快决出冠军，可选单打或固定双打。

双败淘汰

累计两败出局。败者组冠军赢下总决赛时，再打一场重置决赛。

分组淘汰

先组内循环，再交叉淘汰。按分组数和晋级人数检查参赛规模；出线边界完全同分时由负责人办理晋级抽签。

具体分制以赛事设置为准，发送“赛事名，规则”查询。五人转、五羽伦比不用于混双；混双可选双打轮转或固定双打赛制。

06

看懂回复与处理问题

注册、审核与会籍

“注册申请已提交 / 待审核”
申请已保存，尚未获批。发送“注册资料”查状态，等待会员管理员审核，不必重复提交。
“注册审核未通过 / 会员已停用”
未通过时核对并修改资料后重新申请；停用时联系管理员恢复，不靠重复注册解决。
“注册链接已失效”
回群 @负责注册的机器人重新发送“注册”，打开最新本人链接；链接20分钟有效。
“已关联管理员预登记资料 / 您已注册”
注册已经完成，无需再次申请。用“帮助”查看可用业务，报名仍要满足会籍和活动条件。
“暂不能新报名 / 有效期未覆盖活动日期”
先查“我的会籍”，联系管理员登记相应有效期后再报名；仍可查历史和取消已有报名。

报名与取消

“报名已确认”
核对日期、时间、场地、本人及同行名单。本人重复报名不多占位；每次“报名+N”都会新增N位同行。
“正式 / 替补 / 候补”
这是活动名额：正式位满后排替补，再排候补。取消后按顺序递补；代报人员占名额，不等于注册会员。
“暂无报名”
该场目前没有有效报名。想参加时发送含日期和场次的报名指令。
“未找到唯一可用场次 / 活动场次已调整”
按回复里的可用场次补充日期、时间或场次；先重新查询名单，再提交。
“本人当前未报名，无需取消”
本人没有有效报名；同行可能仍在名单，先查名单，再按姓名取消本人代报的人。
“同行人员…已由您报名 / 未找到本人代报的唯一有效人员”
核对本场名单中的同行姓名。“取消报名”只取消自己；不能取消别人代报的人。
提示等级、组别不符合或同行须独立报名
核对已审核等级和组别；有这些限制时，同行须自行注册、审核并独立报名。处理条件后再报名，本次未新增报名。

机器人与权限

“当前时段未开放”
该业务有开放时间限制，请在开放时段重试，或向管理员确认安排。
“当前机器人未开启…”
先发送“帮助”确认业务，改用提供该业务的机器人，或请机器人管理员在后台开启。
“本机器人或群未负责此场地/时段”
选择它负责的场次，或 @负责目标场次的机器人；同一后台无需重新注册。
“当前没有管理权限 / 无本赛事记分权限”
发送“我的权限”核对管理角色；赛事记分请负责人确认职务及授权期。
“未识别指令，本次未执行”
发送“帮助”，复制其中的指令并替换参数；支持AI时可用“AI + 完整需求”重新表达。
@后没有任何回复
先确认 @的是目标机器人，再用“帮助”查询。仍无回复时请管理员检查机器人与群是否启用、是否接收指令及回调/发送记录；先查名单或记录，避免重复提交写入操作。

比赛与零散对局

“请先发送 组织比赛 / 策划已过期”
先发起策划，看人数与可用赛制，再选赛制。已经生成的赛事用名称查询或“继续比赛”，不必重新建赛。
赛制显示不可用、人数不足或性别待补齐
按提示补齐报名、性别，或切换单打/双打项目及赛制。混双要求合适的男女组合。
“存在多场进行中赛事 / 存在同名赛事”
记分写明赛事名称；仍重名时加日期。使用对战表里的对局编号，不是当天第几场活动。
“该赛事没有此场次 / 尚未开放记分”
查“赛事名，对战表”，核对对局编号及赛事状态；暂停或未就绪时联系负责人。
“请选择…对应的会员”
对照姓名、性别、等级和组别，回复候选序号“选择1”等；不确定先问本人。
“本次未重复记入”
这是零散对局的重复提醒。确实又打了一局才回复“重复记录”；否则不用继续。
“未找到…人员匹配的未结束赛事”
核对当前群、场地及报名人员；已有赛事可按名称查对战表并由负责人恢复，确需新赛再“组织比赛”。

AI预览、确认与结果

“AI 查询 · 后台结果”
查询已经完成，无需确认。需要改变报名或设置时再表达新需求。
“AI 待确认 / AI 计划待确认 · 尚未执行”
先看编号步骤，再由本人在原群 @对应机器人回复“确认”。每人只保留一份当前方案；修改请发送“AI + 修改意见”。
“计划未通过检查 / 信息不足 / 未识别出明确操作”
本次没有办理。按提示补全日期、场地、场次、姓名或赛事名称，再发送完整需求。
“确认已过期 / 业务配置或人员已变化”
重新发送 AI 加业务需求，核对新预览后回复“确认”。
“AI 计划已完成 / AI 已确认 · 执行结果”
查看实际业务回执。多步计划可用“AI进度”回看每一步。
“AI 计划执行中止”
已完成步骤保留，后续步骤未执行。先用“AI进度”及业务名单核对，再只办理剩余操作，勿整单重做。
“AI业务助手未开启 / AI暂不可用”
使用固定指令继续办理；需要恢复AI时联系系统管理员，并确认当前机器人也开启了AI业务。
